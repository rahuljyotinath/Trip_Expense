# Tripzy for operators — pricing one-pager (India)

Strategy context: [ceo-spec.md](./ceo-spec.md).

**Users never pay.** Businesses pay for roster workflow, export, and brand.

## Operator / trek / homestay pack

- Branded invite link (subpath or query brand)
- CSV import roster + export for accounts
- Multiple concurrent trips
- **₹2,000–15,000 / month** by active trips or seat cap

## Corporate offsite

- HR roster import, finance read-only export
- Trip archive after event
- **₹5,000–25,000 per event** or annual seat pack

## Wedding / event planner

- Co-branded trip links for each function / side of family
- **₹1,000–5,000 / month** per planner seat

## College society

- Fest / trip committee; sponsor via local brand or institute IT budget
- **Custom** (often sponsored)

## Included today (self-serve)

- Trip CSV export (opener)
- Trip CSV import (opener)
- Invite link + join code

## Roadmap for paid tiers

- Org dashboard (multi-trip)
- Custom domain on invite
- Aggregate analytics (bands, no PII resale)
