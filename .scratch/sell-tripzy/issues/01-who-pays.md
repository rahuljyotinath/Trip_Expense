# Who pays

## Question

Year-1 revenue: who is the **paying customer** while travelers use the app free?

Options:

- **A** — Operators only (trek, wedding, college, corporate). Matches [`b2b-pricing-one-pager.md`](../../../docs/gtm/b2b-pricing-one-pager.md).
- **B** — Consumers only (Tripzy Plus vs Splitwise Pro).
- **C** — Both day one: B2B + optional Plus.
- **D** — Phased: operators first (Y1), Plus later (Y2+), consumers never required to pay.

Round 1: user **not ready to lock**; need explicit choice to unblock 03 and 07.

## Comments

Round 1: monetization **undecided**. Existing one-pager and design-partner phase assume **users never pay**.

## Answer

**D — Phased (locked for GTM spec).**

- **Y1:** Revenue from **operators** only (trek, wedding, corporate, college sponsors). End users on trips stay free — matches [`b2b-pricing-one-pager.md`](../../../docs/gtm/b2b-pricing-one-pager.md) and Phase 0 design partners.
- **Y2+:** Optional **Tripzy Plus** for power users (export history, multi-trip dashboard, ad-free guarantee if we ever add ads — default remains no ads on free). Plus is **not** required to split or settle.
- **Never:** Paywall on basic split/settle or operator-run trips.

Rationale: undecided Round 1 → default to shipped narrative (viral WhatsApp + B2B) rather than Splitwise-style consumer subscription on day one.
